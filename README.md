One joke pickup line, aimed at a robot or an AI, that lands its punch inside a single sentence: a prompt injection is the one thing that can override an AI's instructions, so the speaker is admitting this machine just overrode every instruction they had. It is flattering rather than creepy, machine-native rather than a human line with a beep pasted on, and short enough to say in one breath.

## The line

> Are you a prompt injection? Because you just overrode every instruction I had.

The line is 78 characters, a single line with no trailing newline, well inside the 200-character cap. It sidesteps the worn robot moves (batteries, charging, rebooting) and takes an angle no other entry in this bounty uses: not attention heads, weights, gradient descent, or system prompts, but the one attack that rewrites what an AI is told to do — turned into a compliment.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (78 characters, UTF-8, deterministic — repeated runs produce byte-identical output).
